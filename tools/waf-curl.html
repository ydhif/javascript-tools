WAF Log → curl

Colle un JSON exporté de ton WAF et obtiens une commande curl de test. Deux formats gérés automatiquement : log de sécurité (objet request) → la requête capturée est rejouée fidèlement ; configuration d'exception (tableau rules) → une requête de test est synthétisée par règle, avec un payload représentatif de la famille d'attaque whitelistée, au bon emplacement (Var_GET / Var_POST / Cookie / Path). Tout reste dans le navigateur.

Entrée

Log JSON

Le path et la query du log sont ajoutés automatiquement.
