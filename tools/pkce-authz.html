PKCE & Authz URL Builder

Génère un couple code_verifier / code_challenge (S256) via WebCrypto et construit une URL d'autorisation OIDC complète, prête à ouvrir pour déclencher un flow response_type=code.

Étape 1

PKCE (RFC 7636)

Le code_verifier est un secret haute entropie que seul le client connaît. Le code_challenge est base64url(SHA-256(code_verifier)), envoyé dans la requête d'autorisation. Lors de l'échange du code contre un token, le client prouve qu'il détient le code_verifier.
